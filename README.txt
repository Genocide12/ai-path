ПУТЬ AI-ИНЖЕНЕРА — офлайн-самоучитель (PWA)
=============================================

СОСТАВ ПАКЕТА
  index.html    — всё приложение целиком (HTML + CSS + JS, без зависимостей)
  manifest.json — манифест PWA (название, иконки, тема)
  sw.js         — service worker (офлайн-кэш для хостинга)
  icon-192.png  — иконка 192×192
  icon-512.png  — иконка 512×512

КАК ПОЛЬЗОВАТЬСЯ БЕЗ ХОСТИНГА
  Откройте index.html двойным кликом в любом современном браузере.
  Все 6 вкладок, дневник, экзамен и прогресс работают полностью офлайн.
  Прогресс хранится локально в браузере (localStorage).

КАК СДЕЛАТЬ УСТАНАВЛИВАЕМОЕ PWA (GitHub Pages, ~5 минут, без командной строки)
  1. На github.com создайте новый ПУБЛИЧНЫЙ репозиторий, например: ai-path
  2. Нажмите «Add file → Upload files» и перетащите все 5 файлов этого пакета
  3. «Commit changes»
  4. Settings → Pages → Branch: main, папка / (root) → Save
  5. Через 1–2 минуты приложение откроется по адресу:
     https://ВАШ_ЛОГИН.github.io/ai-path/
  6. На телефоне откройте этот адрес → меню браузера →
     «Добавить на главный экран» — приложение установится как PWA
     с иконкой и будет работать офлайн.

ОБНОВЛЕНИЕ ПРИЛОЖЕНИЯ
  Тем же способом: «Upload files» → перетащите новый index.html →
  «Commit changes». Service worker подхватит новую версию:
  сначала закройте вкладку/приложение, при следующем открытии
  обновление применится (при необходимости — дважды, или очистите
  данные сайта).

ПЕРЕНОС ПРОГРЕССА МЕЖДУ УСТРОЙСТВАМИ
  Вкладка «Главная» → «Настройки и данные» → «Экспорт прогресса»
  (скачается JSON-файл) → на другом устройстве «Импорт прогресса».

ВАЖНО ПРО БЕЗОПАСНОСТЬ
  Никогда не пересылайте GitHub-токены текстом в чатах и мессенджерах.
  Токен, попавший в переписку, считается скомпрометированным:
  GitHub → Settings → Developer settings → Personal access tokens → Delete.
